# Proyecto TypeScript: TP Integrador

Trabajo práctico individual de investigación en TypeScript del Instituto Politécnico Formosa. Incluye un archivo de ejemplos por cada uno de los 6 temas (en `src/`) y un glosario (`GLOSARIO.md`).

**Alumna:** _Aguirre Fernandez Ana Belén Alejandra_

## Uso

```bash
npm install                        # instala las dependencias
npx tsx src/tema1.ts    # ejecuta un tema puntual
npm run check                      # verifica los tipos
npm run build && npm start         # compila y ejecuta
```
